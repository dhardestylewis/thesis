### Machine Learning & Planning Data
- **Abuloc Jr., Regor Martin (2024)**: *Evolving the Planning Paradigm: A Machine Learning Framework for Efficient City Planning*. (Excellent for methodology structure). [Link](https://viurrspace.ca/items/67634f59-22a4-44b4-8250-9d88581f0082)

### NIMBYism & Opposition Theory (Non-ML but Core Grounding)
- **Einstein, Katherine Levine (2019)**: *Neighborhood Defenders: Participatory Politics and America's Housing Crisis*. (The fundamental book on who opposes housing and why).
- **Hankinson, Michael (2018)**: *When do renters behave like homeowners? High rent, price-based NIMBYism, and support for new housing*. (Key statistical analysis of opposition motives).
- **Smith, Robert W. (UC Berkeley)**: *Towards a Theory of Movement Planning Practice*. (Deep dive into the "NIMBY" response in planning).
