# Draft-TBD

Active thesis writing workspace (To Be Developed).

## Purpose

This directory is intentionally empty and reserved for your thesis LaTeX files and chapters. The `-TBD` suffix indicates this is a placeholder that will be filled during thesis writing.

## Intended Contents

```
Draft-TBD/
├── main.tex                 # Main thesis document
├── chapters/               # Individual chapter files
│   ├── 01_introduction.tex
│   ├── 02_background.tex
│   ├── 03_methods.tex
│   ├── 04_results.tex
│   └── 05_conclusion.tex
├── figures/                # Figures and images
├── tables/                 # Table files
├── appendices/             # Appendix content
├── README.md (this file)
└── references.bib          # Bibliography (or link to References/bibliography/)
```

## Getting Started

When ready to begin writing:

1. **Copy proposal background**: Adapt content from `References/Background-COMPREHENSIVE.d/`
2. **Set up LaTeX structure**: Create `main.tex` and chapter files
3. **Link bibliography**: Use `References/bibliography/references.bib`
4. **Reference materials**: See `References/` for all supporting materials
5. **Follow guidelines**: Check `References/UP_Thesis_Guidelines_Searchable_OCR.pdf`

## Related Directories

- **References/**: Background research, bibliography, example theses
- **Data/**: Research datasets for analysis
- **Analysis/**: Notebooks producing figures and results
- **Archive/**: Historical draft versions (for reference only)
- **Submitted/**: Approved proposal to reference
