# Appraisal Rolls Data

Large data files in this directory (CSV, TXT, PKL, ZIP) are excluded from the GitHub repository due to file size limits (GitHub limits files to 100MB).

## Data Organization
- **Standardized Naming**: All files follow the `EARS_YYYY_Description.ext` convention.
- **Record Types**:
    - `Jurisdiction_Tax_Values`: Primary appraisal roll records with values and exemptions.
    - `Ag_Timber_Details`: Details for agricultural and timber productivity valuation.
    - `Top_Taxpayers`: List of the top 10 taxpayers in each taxing unit.
    - `Property_Address_Legal`: Address and legal descriptions.
    - `Owner_Metadata`: Owner names and addresses.
    - `Category_Details`: Specific account category data.

## Restoration
To restore this data, please refer to the project's external backup on the G: Drive or S3 (as noted in `.meta/TODO.md`).
