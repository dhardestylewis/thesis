## Naming Convention

Files are named `{Category}_{LabeledYear}_{DatasetID}.csv`:
- **LUI** = Land Use Inventory
- **LDB** = Land Database (richer: includes zoning, appraisal, structure data)
- **ZC** = Zoning Cases
- **ZBA** = Zoning By Address
- **JURISDICTIONS** = City boundary polygons
