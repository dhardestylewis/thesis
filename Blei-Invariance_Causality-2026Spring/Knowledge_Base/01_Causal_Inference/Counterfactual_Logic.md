# Counterfactual Logic and Axioms

Compendium of axioms and formal logic for counterfactual reasoning (Pearl Chapter 4).

## Fundamental Axiom
*   **Composition:** $W_x(u) = w$ if $X(u) = x$. (If we intervene and set $X$ to the value it would have taken naturally, the outcome is unchanged).
